# Scala 隐式双元操作符需求文档

## 1. 概述

本需求定义一组 Scala 隐式转换（implicit conversion）支持的**双元操作符（binary operators）**，用于以中缀表达式（infix notation）的方式组合函数与处理数据。

操作符共分为两大类：

- **函|函**：左侧为函数，右侧为函数，将两个函数按特定规则组合成新函数。
- **数|函**：左侧为任意值或可迭代对象，右侧为函数，将数据通过管道传递给函数处理。

总计 **30 个操作符**（15 对，每对包含正向与反向两种形式）。

## 2. 设计原则

1. **中缀优先**：所有操作符均设计为 Scala 中缀调用风格，形如 `left op right`。
2. **方向明确**：正向操作符表示"从左到右"的数据/函数组合；反向操作符表示"从右到左"。
3. **类型安全**：组合规则由编译期类型推导决定，尽可能在编译期捕获错误。
4. **懒求值**：函数组合返回新函数，不立即执行，仅在调用时求值。
5. **参数解包一致**：涉及解包（`*` 前缀）的操作符，统一采用元组/列表解包语义。
6. **错误延迟**：解包后参数数量超出右侧函数可容纳数量时，**生成时不报错，运行时报错**。

## 3. 操作符总览

### 3.1 函|函 操作符（9 对 = 18 个）

| 9 | `~~>>` | `<<~~` | `(D, F) => A` | `(A, B) => C` | `(D, F, B) => C` | 双参函数结果作为双参函数首参 |

### 3.2 数|函 操作符（6 对 = 12 个）

| 编号 | 正向 | 反向 | 左侧 | 右侧 | 返回 | 说明 |
|------|------|------|------|------|------|------|
| 1 | `\|>` | `<\|` | 任意值 `A` | `(A) => B` | `B` | 管道：值作为单参函数输入 |
| 2 | `\|>>` | `<<\|` | 可迭代 `Iterable[A]` | `(A) => B` | `Iterable[B]` | 映射：类似 `map` |
| 3 | `\|?>` | `<?\|` | 可迭代 `Iterable[A]` | `(A) => Boolean` | `Iterable[A]` | 过滤：类似 `filter` |
| 4 | `\|*>` | `<*\|` | 可迭代 `Iterable[A]`（A 可迭代） | `(A) => B` | `Iterable[B]` | 展平映射：类似 `flatMap` |
| 5 | `\|&>` | `<&\|` | 可迭代 `Iterable[A]` | `(A, A) => A` | `A` | 归约：类似 `reduce` |
| 6 | `\|@>` | `<@\|` | 可迭代 `Iterable[A]` | 柯里化 `(G)(A) => G` | `G` | 折叠：类似 `fold`，需初始值 |

## 4. 详细需求

### 4.1 函|函 操作符

#### 4.1.1 `o>` / `<o`：无参函数 → 单参函数

**类型签名**

```scala
o> [A, B]: (() => A, A => B) => (() => B)
<o [A, B]: (A => B, () => A) => (() => B)
```

**语义**

- 左侧函数无参数，调用后产生值 `A`。
- 右侧函数接收单个 `A` 类型参数，产生 `B`。
- 组合后的函数无参数，调用时先执行左侧函数，将其结果传入右侧函数。

**示例**

```scala
def genA(): String = "Hello"
def genB(s: String): String = s"$s, World!"

val merged = genA _ o> genB _
assert(merged() == "Hello, World!")

// 反向
val mergedRev = genB _ <o genA _
assert(mergedRev() == "Hello, World!")
```

---

#### 4.1.2 `o>>` / `<<o`：无参函数 → 双参函数

**类型签名**

```scala
o>> [A, B, C]: (() => A, (A, B) => C) => (B => C)
<<o [A, B, C]: ((A, B) => C, () => A) => (B => C)
```

**语义**

- 左侧函数无参数，调用后产生值 `A`。
- 右侧函数需要两个参数 `(A, B)`，返回 `C`。
- 组合后的函数接收参数 `B`，并将左侧结果作为首参数 `A` 传入右侧函数。

**示例**

```scala
def genA(): String = "Hello"
def genB(s: String, name: String): String = s"$s, $name!"

val merged = genA _ o>> genB _
assert(merged("World") == "Hello, World!")
```

---

#### 4.1.3 `*o>` / `<o*`：无参函数 → 解包应用

**类型签名**

```scala
*o> [A, B, R]: (() => Seq[A], (A, A, ...) => B) => (剩余参数 => B)
<o* [A, B, R]: ((A, A, ...) => B, () => Seq[A]) => (剩余参数 => B)
```

**语义**

- 左侧函数无参数，返回一个**可迭代对象**（Tuple、List、Seq 等）。
- 右侧函数需要至少一个参数。
- 组合时，将左侧函数返回的可迭代对象**解包**为参数列表，预填充到右侧函数中。
- 若解包后的参数数量不足右侧函数必需参数数量，返回一个接收剩余参数的新函数。
- 若解包后的参数数量超过右侧函数可容纳的最大参数数量，**生成时不报错，运行时报错**。

**示例**

```scala
def genA(): List[String] = List("Hello")
def genB(s: String, name: String): String = s"$s, $name!"

val merged = genA _ *o> genB _
assert(merged("World") == "Hello, World!")
```

**边界情况**

- 左侧函数返回空序列，且右侧函数需要参数：运行时抛出参数不足异常。
- 左侧函数返回 `(1, 2, 3)`，右侧函数只需要 `(A, B)`：运行时抛出参数过多异常。

---

#### 4.1.4 `~>` / `<~`：单参函数 → 单参函数

**类型签名**

```scala
~> [D, A, B]: (D => A, A => B) => (D => B)
<~ [D, A, B]: (A => B, D => A) => (D => B)
```

**语义**

- 左侧函数接收 `D`，返回 `A`。
- 右侧函数接收 `A`，返回 `B`。
- 组合后的函数接收 `D`，先调用左侧函数，再将其结果传入右侧函数。
- 等价于函数复合（function composition）：`g compose f`。

**示例**

```scala
def f(h: String): String = s"$h Are"
def g(s: String): String = s"$s You?"

val merged = f _ ~> g _
assert(merged("How") == "How Are You?")
```

---

#### 4.1.5 `~>>` / `<<~`：单参函数 → 双参函数

**类型签名**

```scala
~>> [D, A, B, C]: (D => A, (A, B) => C) => ((D, B) => C)
<<~ [D, A, B, C]: ((A, B) => C, D => A) => ((D, B) => C)
```

**语义**

- 左侧函数接收 `D`，返回 `A`。
- 右侧函数需要 `(A, B)`，返回 `C`。
- 组合后的函数接收 `(D, B)`，将左侧函数作用在 `D` 上的结果作为首参数 `A`。

**示例**

```scala
def f(h: String): String = s"$h Are"
def g(s: String, name: String): String = s"$s You? $name!"

val merged = f _ ~>> g _
assert(merged("How", "Victor") == "How Are You? Victor!")
```

---

#### 4.1.6 `*~>` / `<~*`：单参函数 → 解包应用

**类型签名**

```scala
*~> [D, A, B, R]: (D => Seq[A], (A, A, ...) => B) => ((D, 剩余参数) => B)
<~* [D, A, B, R]: ((A, A, ...) => B, D => Seq[A]) => ((D, 剩余参数) => B)
```

**语义**

- 左侧函数接收 `D`，返回可迭代对象。
- 右侧函数需要至少一个参数。
- 将左侧函数结果解包后预填充到右侧函数。

**示例**

```scala
def f(name: String): List[String] = List("Hi", name)
def g(s: String, name: String, other: String): String = s"$s, $name, $other"

val merged = f _ *~> g _
assert(merged("Victor", "what can I do for you?") == "Hi, Victor, what can I do for you?")
```

---

#### 4.1.7 `~~>` / `<~~`：双参函数 → 单参函数

**类型签名**

```scala
~~> [D, F, A, B]: ((D, F) => A, A => B) => ((D, F) => B)
<~~ [D, F, A, B]: (A => B, (D, F) => A) => ((D, F) => B)
```

**语义**

- 左侧函数接收 `(D, F)`，返回 `A`。
- 右侧函数接收 `A`，返回 `B`。
- 组合后的函数接收 `(D, F)`，先调用左侧函数，再将其结果传入右侧函数。

---

#### 4.1.8 `*~~>` / `<~~*`：双参函数 → 解包应用

**类型签名**

```scala
*~~> [D, F, A, B, R]: ((D, F) => Seq[A], (A, A, ...) => B) => ((D, F, 剩余参数) => B)
<~~* [D, F, A, B, R]: ((A, A, ...) => B, (D, F) => Seq[A]) => ((D, F, 剩余参数) => B)
```

**语义**

- 左侧函数接收 `(D, F)`，返回可迭代对象。
- 右侧函数需要至少一个参数。
- 将左侧函数结果解包后预填充到右侧函数。

**边界情况**

- 左侧返回二元组，右侧只需要 1 个参数：运行时报错（参数过多）。
- 左侧返回二元组，右侧需要 3 个参数：返回接收第 3 个参数的函数。

**示例**

```scala
def f(d: String, f: String): (String, String) = (d, f)
def g(a: String, b: String, c: String): String = s"$a, $b, $c"

val merged = f _ *~~> g _
assert(merged("Hello", "World", "!") == "Hello, World, !")
```

---

#### 4.1.9 `~~>>` / `<<~~`：双参函数 → 双参函数

**类型签名**

```scala
~~>> [D, F, A, B, C]: ((D, F) => A, (A, B) => C) => ((D, F, B) => C)
<<~~ [D, F, A, B, C]: ((A, B) => C, (D, F) => A) => ((D, F, B) => C)
```

**语义**

- 左侧函数接收 `(D, F)`，返回 `A`。
- 右侧函数需要 `(A, B)`，返回 `C`。
- 组合后的函数接收 `(D, F, B)`，将左侧结果作为右侧首参数。

## 4.2 数|函 操作符

### 4.2.1 `|>` / `<|`：值 → 函数

**类型签名**

```scala
|> [A, B]: (A, A => B) => B
<| [A, B]: (A => B, A) => B
```

**语义**

- 左侧为任意值 `A`。
- 右侧为接收 `A` 的函数。
- 将左侧值作为参数调用右侧函数，返回结果。
- 等价于函数应用（function application）：`f(x)`。

**示例**

```scala
val result = "hello" |> (_.toUpperCase)
assert(result == "HELLO")
```

---

### 4.2.2 `|>>` / `<<|`：可迭代对象 → map

**类型签名**

```scala
|>> [A, B]: (Iterable[A], A => B) => Iterable[B]
<<| [A, B]: (A => B, Iterable[A]) => Iterable[B]
```

**语义**

- 左侧为可迭代对象 `Iterable[A]`，或任何可转换为可迭代对象的结构。
- 右侧为 `A => B` 的映射函数。
- 对左侧每个元素应用右侧函数，返回新的可迭代结果。
- 等价于 `left.map(right)`。

**示例**

```scala
val result = List(1, 2, 3) |>> (_ * 2)
assert(result == List(2, 4, 6))
```

---

### 4.2.3 `|?>` / `<?|`：可迭代对象 → filter

**类型签名**

```scala
|?> [A]: (Iterable[A], A => Boolean) => Iterable[A]
<?| [A]: (A => Boolean, Iterable[A]) => Iterable[A]
```

**语义**

- 左侧为可迭代对象。
- 右侧为返回 `Boolean` 的断言函数。
- 保留使右侧函数返回 `true` 的元素。
- 等价于 `left.filter(right)`。

**示例**

```scala
val result = List(1, 2, 3, 4) |?> (_ % 2 == 0)
assert(result == List(2, 4))
```

---

### 4.2.4 `|*>` / `<*|`：可迭代对象 → flatMap

**类型签名**

```scala
|*> [A, B]: (Iterable[Iterable[A]], A => B) => Iterable[B]
<*| [A, B]: (A => B, Iterable[Iterable[A]]) => Iterable[B]
```

**语义**

- 左侧为可迭代对象，其元素本身也可能是可迭代对象。
- 右侧为 `A => B` 的映射函数。
- 先将左侧元素展平（flatten），再对每个元素应用右侧函数。
- 等价于 `left.flatten.map(right)`。

**示例**

```scala
val result = List(List(1, 2), List(3, 4)) |*> (_ * 10)
assert(result == List(10, 20, 30, 40))
```

---

### 4.2.5 `|&>` / `<&|`：可迭代对象 → reduce

**类型签名**

```scala
|&> [A]: (Iterable[A], (A, A) => A) => A
<&| [A]: ((A, A) => A, Iterable[A]) => A
```

**语义**

- 左侧为可迭代对象 `Iterable[A]`。
- 右侧为二元合并函数 `(A, A) => A`。
- 使用右侧函数对左侧元素进行两两合并，最终返回一个 `A` 类型的聚合值。
- 等价于 `left.reduce(right)`。
- 左侧为空时，运行时报错（与 `reduce` 行为一致）。

**示例**

```scala
val result = List(1, 2, 3, 4) |&> (_ + _)
assert(result == 10)
```

---

### 4.2.6 `|@>` / `<@|`：可迭代对象 → fold

**类型签名**

```scala
|@> [A, G]: (Iterable[A], G => (G, A) => G) => G
<@| [A, G]: (G => (G, A) => G, Iterable[A]) => G
```

**语义**

- 左侧为可迭代对象 `Iterable[A]`。
- 右侧为**柯里化**的二元函数：`G => (G, A) => G`，即先接收初始值 `G`，再接收 `(G, A)` 返回 `G`。
- 需要提供初始累加值 `G`，最终返回 `G` 类型的聚合值。
- 等价于 `left.foldRight(init)(op)` 或 `left.foldLeft(init)(op)`。

**示例**

```scala
def folder(init: Int)(acc: Int, x: Int): Int = acc + x

val result = List(1, 2, 3, 4) |@> folder _
// 调用柯里化函数
val sum = result(0)
assert(sum == 10)
```

## 5. 可迭代对象约定

"可迭代对象"指满足以下条件之一的值：

1. Scala 标准 `Iterable[A]` 子类型。
2. Java `java.lang.Iterable[A]` 子类型。
3. 具有 `toSeq`、`toList`、`iterator` 等可转换为迭代器的方法。
4. 隐式转换可转换为 `Iterable[A]` 的类型。

对于 `|*>` 操作符，额外要求：**元素本身也可以是可迭代的**，此时需要进行深度或单层展平（默认单层展平）。

## 6. 反向操作符规则

所有反向操作符都是正向操作符的参数顺序镜像：

```scala
// 正向
left op right

// 反向
right reverse_op left
```

即：反向操作符不改变语义，只改变操作数的书写顺序。

| 正向 | 反向 |
|------|------|
| `o>` | `<o` |
| `o>>` | `<<o` |
| `*o>` | `<o*` |
| `~>` | `<~` |
| `~>>` | `<<~` |
| `*~>` | `<~*` |
| `~~>` | `<~~` |
| `*~~>` | `<~~*` |
| `~~>>` | `<<~~` |
| `\|>` | `<\|` |
| `\|>>` | `<<\|` |
| `\|?>` | `<?\|` |
| `\|*>` | `<*\|` |
| `\|&>` | `<&\|` |
| `\|@>` | `<@\|` |

## 7. 错误处理

| 错误场景 | 行为 | 阶段 |
|----------|------|------|
| 函数参数类型不匹配 | 编译期类型错误 | 编译期 |
| 解包后参数不足 | 运行时抛出 `IllegalArgumentException` 或 Scala 默认异常 | 运行期 |
| 解包后参数过多 | 运行时抛出 `IllegalArgumentException` | 运行期 |
| `|&>` 作用于空集合 | 运行时抛出 `UnsupportedOperationException` | 运行期 |
| 左侧不可迭代但用于数\|函操作符 | 编译期类型错误（无隐式转换） | 编译期 |

## 8. 实现提示

1. 使用 Scala `implicit class` 为函数、值、可迭代对象扩展操作符方法。
2. 使用变长参数 `T*` 或 shapeless/Tuple 支持解包操作符。
3. 建议通过 `scala.FunctionN` 的类型参数推断减少样板代码。
4. 数\|函操作符的结果类型建议与输入集合类型一致（如 `List[A] |>> f` 返回 `List[B]`）。

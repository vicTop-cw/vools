# CHANGELOG 0.7.0

## 主要更新

### 新增 `flex_pos` 灵活占位符装饰器

新增 `vools.decorators.flex_pos` 装饰器，提供类似 Scala/Scala 的 `_` 占位符语法糖，将表达式自动转换为 lambda 函数。

#### 核心特性

- **表达式占位符**：在被装饰的函数/类体内，`_` 自动转换为 lambda 参数
  - `f = _` → `lambda x: x`
  - `f = _ + 1` → `lambda x: x + 1`
  - `f = _['key']` → `lambda x: x['key']`
  - `f = _[_]` → `lambda x, y: x[y]`
  - `f = add_plain(_, 3)` → `lambda x: add_plain(x, 3)`
  - `f = _.attr[_](2, 3, 4, _)[0]` → 多参数 lambda
- **可变参数签名标记**：使用 `_` / `__` 作为函数签名中的特殊参数
  - `_` 转换为 `*args`
  - `__` 转换为 `**kwargs`
  - 自动向函数体注入 `args` 和 `kwargs` 变量
  - `_` 与 `*args` 不能共存，`__` 与 `**kwargs` 不能共存
  - `__` 不能写在 `_` 前面
- **类装饰支持**：`@flex_pos` 可直接装饰类，递归转换类体中所有方法
  - 支持 `__init__`、实例方法、`@classmethod`、`@staticmethod`
  - 支持方法内部嵌套函数和嵌套类
- **嵌套装饰器支持**：外层和内层同时使用 `@flex_pos`
  - 通过 `linecache` 注册生成源码，解决 `inspect.getsource` 嵌套获取问题
  - 通过调用者 frame 合并局部变量，支持局部作用域内类的继承
- **Python 3.6+ 兼容**：仅使用标准库，无第三方依赖

#### 使用示例

```python
from vools.decorators.flex_pos import flex_pos, _

@flex_pos
def demo():
    f = _ + 1
    g = _ * 2
    return f(5), g(3)  # (6, 6)

@flex_pos
def collect(prefix, _, __):
    return prefix, args, kwargs

collect('a', 1, 2, x=3, y=4)
# ('a', (1, 2), {'x': 3, 'y': 4})

@flex_pos
class Calculator(object):
    def add_one(self, value):
        return _ + 1

calc = Calculator()
calc.add_one(5)  # 6
```

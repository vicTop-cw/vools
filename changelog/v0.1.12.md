# v0.1.12 更新日志

> 发布日期: 2026-06-05

## 新功能

- 新增 `vools.encoding` 编码模块
  - Base64 编解码
  - JSON 序列化/反序列化
  - 压缩/解压功能（gzip, zlib）
  - 自定义编解码器扩展接口
- 新增 `vools.crypto` 加密模块
  - 哈希函数（MD5, SHA1, SHA256, SHA512）
  - HMAC 消息认证
  - 安全随机数生成
  - 自定义加密算法扩展接口

## 改进

- 所有模块添加 `__all__` 变量，明确导出接口
- 完善全项目公开方法的文档，补充详细的参数说明、返回值和示例
- 合并同名不同义的 `lazy` 函数
- 将 `overloads` 重命名为 `select` 避免命名冲突

## 修复

- 中文输出编码错误修复
- `ast.Str` 已弃用警告修复（Python 3.13 兼容性）
- HMAC 函数参数错误修复

## 兼容性

- 支持 Python 3.6+
- 不依赖 pandas 和 numpy

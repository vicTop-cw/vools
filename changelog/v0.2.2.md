# CHANGELOG 0.2.2

## 主要更新

### Python 双版本兼容性全面保障（3.6 + 3.13）

- **全面双版本测试**：所有非监控类测试（919 个）在 Python 3.6.8 和 Python 3.13.14 上同时通过，0 failed、0 skipped、0 xfailed
- **测试稳定性**：建立双版本并行测试机制，确保每次变更都同时兼容两个版本

### 核心兼容模块体系化

- **asyncio_compat 移入 core**：将 `vools.utils.asyncio_compat` 重构为 `vools.core.asyncio_compat`，与 dataclass_compat 保持一致的架构
- **新增 asyncio.create_task 兼容**：为 Python 3.6 提供 `create_task` 兼容实现（底层使用 `asyncio.ensure_future`）
- **新增 inspect_compat 模块**：`vools.core.inspect_compat` 统一 inspect 接口，导出 signature、Parameter、Signature、getsource、getfile、iscoroutinefunction、isclass、isfunction
- **新增 datetime_compat 模块**：`vools.core.datetime_compat` 提供 `datetime_fromisoformat`、`date_fromisoformat`、`time_fromisoformat`，兼容 Python 3.6

### dataclass_compat 增强

- **FrozenInstanceError 兼容**：新增 `FrozenInstanceError` 导出，3.7+ 使用标准库，3.6 使用 attrs 的 `FrozenInstanceError`
- **__post_init__ 自动适配**：attrs backport 模式下自动将 `__post_init__` 映射为 `__attrs_post_init__`，确保 dataclass 初始化逻辑正常工作

### 序列化框架兼容性修复

- **object.__getstate__ 检测**：修复 Python 3.6 中 `object` 类无 `__getstate__` 导致的 `AttributeError`，添加安全检测逻辑
- **VText 序列化修复**：修复内置子类 `__getstate__` 检测逻辑，3.6 环境下 VText 等类型序列化正常

### 安全评估模块 AST 兼容

- **safe_eval 兼容旧版 AST**：支持 Python 3.6 的 `ast.Num`、`ast.Str`、`ast.NameConstant` 节点类型，不再仅依赖 Python 3.8+ 的 `ast.Constant`

### Reactive 模块 asyncio 兼容

- **operators.py**：所有 `asyncio.create_task()` 调用改用 `asyncio_compat.create_task`
- **extended_operators.py**：所有 `asyncio.create_task()` 调用改用 `asyncio_compat.create_task`
- **schedulers.py**：`AsyncIOScheduler` 使用兼容版 `get_running_loop`

### Task 模块 SQLite 兼容

- **storage.py**：使用 `SELECT + UPDATE + SELECT` 替代 `UPDATE ... RETURNING` 语法，兼容旧版 SQLite
- **models.py**：`Task.from_dict` 中的 `datetime.fromisoformat` 改用兼容版 `datetime_fromisoformat`

### 模块级 __getattr__ 兼容

- **datetime 模块**：`vicDate` 延迟导出在 3.6 环境下直接导入，解决模块级 `__getattr__` 不支持的问题
- **decorators 模块**：`extend` 装饰器延迟导出在 3.6 环境下直接导入

### Bridge 模块稳定性

- **FreeBASIC transport**：3.6 环境下 `Protocol` 不可用时回退为 `object`
- **BridgeSigCache**：修复 `id(func)` 作为缓存键导致的对象内存地址复用问题，改用 weakref 跟踪
- **LanguageConfig**：`__post_init__` 在 attrs 模式下正确执行，`version_check` 默认为 `[compiler, --version]`

### 测试文件结构化归档

- **按类别归位子目录**：所有测试文件按功能模块移入对应子目录，共 9 大类
- **新增 utils/ 目录**：编码、加密等工具类测试
- **新增 benchmarks/ 目录**：所有性能基准测试统一归档
- **新增 misc/ 目录**：杂项脚本、对比文档、分析报告等非测试文件
- **Git 历史保留**：所有移动使用 `git mv`，文件修改历史完整可追溯

## 修复

- **asyncio.create_task 缺失**：修复 Python 3.6 中无 `asyncio.create_task()` 导致的 AttributeError
- **datetime.fromisoformat 缺失**：修复 Python 3.6 中无 `datetime.fromisoformat` 导致的 AttributeError
- **object.__getstate__ 缺失**：修复 Python 3.6 中 `object` 类无 `__getstate__` 导致的序列化错误
- **dataclasses.FrozenInstanceError 缺失**：修复 3.6 环境下 dataclasses 模块不可用问题
- **SQLite RETURNING 语法**：修复旧版 SQLite 不支持 `RETURNING` 子句的问题
- **ast.Constant 不存在**：修复 Python 3.6 中 safe_eval 因 AST 节点类型差异导致的安全检查失效
- **模块级 __getattr__ 不支持**：修复 3.6 环境下 `vools.datetime.vicDate`、`vools.decorators.extend` 导入失败
- **BridgeSigCache id 复用**：修复使用 `id(func)` 作为缓存键导致对象销毁后新对象复用内存地址引发的错误缓存命中
- **LanguageConfig version_check None**：修复 FreeBASIC 等桥接配置中 `version_check` 为 None 时调用 `.copy()` 报错

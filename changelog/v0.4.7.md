# CHANGELOG 0.4.7

## 主要更新

### Itor 支持 Nim 版本

将 Nim 版 `itor` 编译为 DLL 并融入 `data` 子包，支持在 Python 中选用 Nim 实现：

- 新增 `use_nim()` 函数，启用后 `get_itor()` 自动使用 Nim 版本
- 新增 `get_itor()` 函数，根据配置自动选择 Python/Nim 实现
- Nim 版通过 `pickle` 序列化支持任意 Python 类型（整数、浮点数、字符串、列表、字典等）
- 当 Nim DLL 不可用时自动回退到 Python 版本

### 参数校验增强

- `send()` 方法新增参数校验：`jump` 和 `jump_when` 不能同时为 `None`
- 当 `jump=None` 但 `jump_when` 不为 `None` 时，`None` 作为合法值插入
- 新增 `ValueError` 异常说明

### 测试完善

- 新增 `test_send_both_none_raises` 测试用例
- 新增 `test_send_jump_none_with_jump_when` 测试用例
- Python 版测试：58 个测试全部通过
- Nim 版测试：17 个测试全部通过

### 清理工作

- 移除了根目录的 `itor.nim` 文件
- 在 `.gitignore` 中添加了 Nim 构建产物规则

## 兼容性

- Python 3.6+
- 已验证版本：3.6.8、3.13.x
- 破坏性 API 变更：无，完全向后兼容 0.4.6

## 使用方式

```python
from vools.data import use_nim, get_itor

# 启用 Nim 版本（仅对整数序列有效）
use_nim(True)

# 获取迭代器（自动使用 Nim 版本）
itor = get_itor([1, 2, 3])
for val in itor:
    print(val)

# 切换回 Python 版本
use_nim(False)
```

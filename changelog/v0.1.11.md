# v0.1.11 更新日志

> 发布日期: 2026-06-05

## 新功能

- 新增 `vools.task` 任务队列模块
- 支持多进程处理（WorkerPool）
- 支持多线程处理（ThreadPool）
- 支持任务重试机制
- 支持任务状态管理（PENDING/RUNNING/RETRYING/FAILED/SUCCESS/CANCEL）
- 新增 `@task` 装饰器
- SQLite 持久化存储
- 原子任务领取（并发安全）
- 租约机制防止任务卡死
- 新增 `vools.encoding` 编码模块
  - Base64 编解码
  - JSON 序列化/反序列化
  - 压缩/解压功能（gzip, zlib）
  - 自定义编解码器扩展接口
- 新增 `vools.crypto` 加密模块
  - 哈希函数（MD5, SHA1, SHA256, SHA512）
  - HMAC 消息认证
  - 安全随机数生成
  - 自定义加密算法扩展接口

## 改进

- 修复 `rself` 装饰器对自身实例处理不当的问题
- 修复 `cache.py` 线程安全问题
- 添加 `Z`, `P`, `X`, `Ops`, `O`, `calltype` 到最外层包导出
- 为 `vicText`, `vicDate`, `vicList` 添加 `do` 方法
- Python 3.6 兼容性支持（dataclass → attrs fallback）
- **移除 pandas 和 numpy 依赖**，使用标准库实现日期功能
- 使用 `datetime` 和 `timedelta` 替代 `pd.date_range`
- 所有模块添加 `__all__` 变量，明确导出接口
- 合并同名不同义的 `lazy` 函数
- 将 `overloads` 重命名为 `select` 避免命名冲突
- 完善全项目公开方法的文档，补充详细的参数说明、返回值和示例

## 修复

- 代码注入漏洞（使用 AST 解析替代直接 eval）
- 路径遍历漏洞（添加路径规范化检查）
- 线程安全漏洞（添加锁保护缓存操作）
- 多进程任务执行时的 pickle 错误
- 测试文件数据库文件占用问题
- 中文输出编码错误

## 移除的功能

- `vicTools.get_insert_sql_for_postgre()` - 依赖 pandas DataFrame 的 PostgreSQL SQL 生成函数

## 文档

- 更新 `vools/task/README.md` 任务队列模块文档
- 更新安全审计报告

## 兼容性

- 支持 Python 3.6+（使用 attrs 兼容 dataclass）
- 不再依赖 pandas 和 numpy，减少安装体积

## 依赖变更

**移除的依赖：**
- pandas>=0.22.0
- numpy>=1.14.0

**保留的核心依赖：**
- wrapt>=2.1.2
- attrs>=17.4.0

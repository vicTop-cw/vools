# CHANGELOG 0.2.1

## 主要更新

### Python 3.6 兼容性进一步完善

- **asyncio 兼容性模块**: 新增 `vools.utils.asyncio_compat` 模块，为 Python 3.6 提供 `asyncio.get_running_loop()` 和 `asyncio.run()` 的兼容实现
- **get_running_loop 兼容**: 使用 `asyncio._get_running_loop()` 作为 3.6 环境下的替代实现
- **asyncio.run 兼容**: 手动实现 `asyncio.run()` 功能，包括事件循环创建、任务取消、资源清理等完整逻辑
- **响应式模块适配**: `AsyncIOScheduler` 改用兼容版 `get_running_loop()`，确保 3.6 环境下正常工作
- **多语言桥接适配**: `bridge._base` 和 `zig.compiler` 中的 `asyncio.run()` 调用改用兼容版本

### 文档完善

- **README 更新**: 更新 Python 版本要求为 3.6+，补充 bridge 子包介绍和项目结构说明
- **子包文档**: 确保所有子包、孙包均有完整 README.md

## 修复

- **asyncio.get_running_loop 缺失**: 修复 Python 3.6 中无 `asyncio.get_running_loop()` 导致的 `AttributeError`
- **asyncio.run 缺失**: 修复 Python 3.6 中无 `asyncio.run()` 导致的 `AttributeError`
- **事件循环清理**: 兼容版 `asyncio.run()` 正确处理事件循环关闭和任务取消

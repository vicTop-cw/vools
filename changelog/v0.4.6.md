# CHANGELOG 0.4.6

## 主要更新

### LibXL 自动注册

在 `Book` 类的 `__init__` 中自动调用 `xlBookSetKey` 注册 LibXL，解除 trial 版本限制：

- 不再需要手动调用 `book.set_key(name, key)`
- A1 单元格可正常写入，不再返回 False
- 不再有 trial 版本的水印提示

### 代码清理

- 删除了 4 个遗留测试文件（`tests/xl/test_repro.py`, `tests/xl/test_thread.py`, `tests/xl/test_viewer.py`, `tests/xl/test_multi_source_viewer.py`）
- 这些测试文件引用了已删除的 `vools.xl.viewer` 模块

## 兼容性

- Python 3.6+
- 已验证版本：3.6.8、3.13.x
- 破坏性 API 变更：无，完全向后兼容 0.4.5

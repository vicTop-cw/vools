# CHANGELOG 0.4.10

## 主要更新

### VText 新增 strip_margin 方法

`strip_margin` 对每行文本进行掐头处理，支持 5 种规则，适合在 Python 字符串中嵌入代码模板（如 Python、Nim、Scala 等）。

#### 处理规则

| 序号 | 前缀 | 处理方式 |
|------|------|----------|
| 1 | `\s*\|` | 移除前缀，保留后面内容 |
| 2 | `\s*#\|` | 整行丢弃（作为注释） |
| 3 | `\s*$\|` | 移除前缀 + 多次 `formatEx` 格式化直到收敛 |
| 4 | `\s*$\d+\|` | 移除前缀 + n 空格缩进 + 多次 `formatEx` 格式化 |
| 5 | 其他 | 原样返回 |

#### 代码模板生成示例

```python
from vools.data import VText

code = VText("""\
#| 这是注释，会被丢弃
$|class {class_name}:
$4|def __init__(self, name):
$8|self.name = name
$4|
$4|def greet(self):
$8|return f\"Hello, {{self.name}}!\"
$|
$|if __name__ == \"__main__\":
$4|obj = {class_name}(\"{instance_name}\")
$4|print(obj.greet())""")

result = code.strip_margin(class_name="Person", instance_name="Alice")
exec(result)  # 输出: Hello, Alice!
```

#### 特性

- `**kwargs` 透传到 `formatEx`，支持变量替换
- `$\d+|` 规则支持任意深度缩进，适合生成 Python、Nim、Scala 等缩进敏感语言
- `#|` 注释行在最终输出中被完全丢弃
- 多次 `formatEx` 直到收敛，支持嵌套变量替换
- 返回新的 `VText` 实例，支持链式调用

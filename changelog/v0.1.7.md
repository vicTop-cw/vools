## 技术细节

`vools/data/seq.py` 中的 `unique` 方法之前存在两个问题：
1. 使用了未定义的变量 `s`（`if i not in s`）
2. 元素被重复添加（同时调用了 `d(i)` 和 `rs.append(i)`）

修复后的实现：
```python
@property
def unique(self):
    rs = []
    s = set()
    d = s.add
    for i in self._evaluate():
        if i not in s:
            d(i)
            rs.append(i)
    return rs
```

# CHANGELOG 0.4.5

## 主要更新

### xl 模块新增文本表格展示器

移除了原有的 GUI 表格查看器（基于 GRD 控件/FreeBASIC），改用纯 Python 实现的文本表格展示器，类似 tabulate 风格，支持在控制台快速预览数据。

**新增功能：**

- `show_table(data, title=None, has_header=True, modal=True, show_index=False)` - 在控制台打印二维表格数据
- `Sheet.show(title=None, has_header=True, modal=True)` - Sheet 对象方法，显示当前工作表
- `Book.show(title=None, has_header=True, modal=True, sheet_names=None)` - Book 对象方法，显示所有工作表
- `sheet_to_2d_list(sheet, has_header=True)` - 将 Sheet 转换为二维列表
- `book_to_sheets_data(book, sheet_names=None)` - 将 Book 转换为多个二维列表
- `dataframe_to_2d_list(df, show_index=False)` - 将 DataFrame 转换为二维列表

**支持的数据源：**

| 类型 | 说明 |
|------|------|
| `list` | 二维列表数据 |
| `Sheet` | vools.xl Sheet 对象 |
| `Book` | vools.xl Book 对象（显示所有工作表） |
| `pandas.DataFrame` | pandas DataFrame（可选显示索引） |

**输出示例：**

```
用户信息表
Name    | Age | City
--------+-----+------------
Alice   | 25  | New York
Bob     | 30  | Los Angeles
Charlie | 35  | Chicago
```

### 代码清理

- 移除了 `vools/xl/viewer/` 目录及 GUI 表格查看器代码
- 移除了 `vools/bridge/freebasic/modules/grd_grid.bas` GRD 控件模块
- 清理了相关测试文件和临时文件

## 兼容性

- Python 3.6+
- 已验证版本：3.6.8、3.13.x
- 破坏性 API 变更：`show_table` 函数签名保持不变，实现从 GUI 改为控制台文本输出

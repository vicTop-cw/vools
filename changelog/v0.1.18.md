# v0.1.18 更新日志

> 发布日期: 2026-06-22

## 概述

overload 和 stuff 模块重构：清理冗余代码，修复关键问题，完善 API 文档。

## 新功能

- `OverloadManager._spawn_manager`: 创建子管理器时复制父级重载函数，支持链式注册后仍能调用父级函数
- `StuffConfig`: 全局/局部配置类 (cache_duration, max_workers, debug, strict)
- `Stuff.reset()`: 重置所有已绑定参数

## 改进

### overload.py

- 清理所有 `do()` 方法（从 OverloadMode、OverloadManager、StrictMode 等类中移除）
- 修复 `__call__` 非 strict 模式的副作用问题：改用 `_create_count_check` 仅检查参数数量
- 修复 `register(export_mode=None)` 返回值：默认返回原函数而非管理器
- 合并 `NewOverloadManager` / `StrictMode` 为单一 `OverloadManager` 类
- 统一 `_validate_mode` 为模块级函数
- 补充缺失 docstring：`__get__`, `__setstate__`

### stuff.py

- 移除旧 API：`register`, `register_by`, `register_stuff`, `fill`, `fill_multi`, `param_name`, `returnStuff`
- 采用新 API：`provide`, `provide_with`, `provide_multi_params`, `aggregate_providers`
- 补充缺失 docstring：`_validate_providers_keys`, `_validate_providers`, `__call__`

## 兼容性

- stuff 旧 API 已完全移除，需迁移到新 API：
  - `register(func)` → `provide(func)` 或 `provide(func, name='param')`
  - `register(param_name=['a','b'])` → `provide_with(names=['a','b'])`
  - `fill(func, providers_pos=2)` → `provide_multi_params(func, count=2)`
  - `fill_multi(*funcs, param_name='x')` → `aggregate_providers(*funcs, name='x')`

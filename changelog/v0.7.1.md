# CHANGELOG 0.7.1

## 主要更新

### 修复 `flex_pos` 在 Python 3.6 / Spark / eval 环境中无法获取源码的问题

在 Python 3.6 以及 Spark、notebook 等通过 `exec` / `eval` 加载代码的环境中，`inspect.getsource` 经常因为 linecache 未命中或 `co_filename` 指向临时文件而抛出 `OSError: could not get source code`。本版本增强了源码获取逻辑。

#### 新增 `_get_source` 辅助函数

- 优先使用标准库 `inspect.getsource` 获取源码
- 当标准路径失败时，fallback 通过 `inspect.getsourcefile` 或 `co_filename` 直接读取物理源文件
- 最后尝试 `linecache` 获取已注册的动态源码（用于嵌套 `flex_pos` 装饰器场景）

#### 兼容性

- 完全保留原有行为
- 所有 67 个 `flex_pos` 单元测试继续通过
- 新增 Spark / eval 模拟验证：通过 `exec` 动态执行的 `@flex_pos` 函数可正常工作

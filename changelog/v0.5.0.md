# CHANGELOG 0.5.0

## 主要更新

### 多语言隐式双元操作符模块

新增 Scala / Kotlin / Nim 三种语言的隐式双元操作符实现，用于函数组合与数据管道处理。

#### 操作符体系

总计 **30 个操作符**（15 对，每对包含正向与反向）：

**函|函 操作符（18 个）**

| 正向 | 反向 | 说明 |
|------|------|------|
| `#>` | `<#` | 无参函数结果传入单参函数 |
| `#>>` | `<<#` | 无参函数结果作为双参函数首参 |
| `*#>` | `<#*` | 无参函数结果解包后预填充 |
| `~>` | `<~` | 单参函数复合 |
| `~>>` | `<<~` | 单参函数结果作为双参函数首参 |
| `*~>` | `<~*` | 单参函数结果解包后预填充 |
| `~~>` | `<~~` | 双参函数结果传入单参函数 |
| `*~~>` | `<~~*` | 双参函数结果解包后预填充 |
| `~~>>` | `<<~~` | 双参函数结果作为双参函数首参 |

**数|函 操作符（12 个）**

| 正向 | 反向 | 说明 |
|------|------|------|
| `\|>` | `<\|` | 值 → 函数（管道应用） |
| `\|>>` | `<<\|` | 可迭代 → map |
| `\|?>` | `<\|?` | 可迭代 → filter |
| `\|*>` | `<*\|` | 可迭代 → flatMap |
| `\|&>` | `<&\|` | 可迭代 → reduce |
| `\|@>` | `<@\|` | 可迭代 → fold |

#### Scala 兼容性

- 移除 `scala.collection.BuildFrom` 依赖
- 兼容 Scala 2.11.x（Spark 2.4.3 默认版本）、2.12.x、2.13.x
- 集合操作符直接使用 `Iterable` 原生方法实现

#### Kotlin 命名适配

因 Kotlin 不支持 `<` 和 `>` 作为方法名开头，使用 ASCII 命名映射：
- `#>` → `#gt`, `<#` → `lt#`
- `\|>` → `pipe`, `\|>>` → `pipeMap`

#### Nim DLL 导出

使用 `exportc` + `dynlib` pragma 导出核心函数，支持外部调用。

# CHANGELOG 0.4.8

## 主要更新

### @cmd 装饰器功能增强

#### 命令名自动推断

`@cmd` 装饰器新增命令名自动推断功能，支持三种调用方式：

```python
# 方式一：无括号调用，函数名即命令名
@cmd
def echo(msg: str):
    pass

# 方式二：传 None，同样使用函数名
@cmd(None)
def echo(msg: str):
    pass

# 方式三：显式指定命令名（原有方式）
@cmd("echo")
def echo_func(msg: str):
    pass
```

- 当 `@cmd` 不带括号使用时，直接以被装饰函数的名称作为命令名
- 当 `@cmd(None)` 带括号传 `None` 时，同样使用函数名作为命令名
- 显式传入字符串时，使用指定的命令名（保持原有行为）

#### PowerShell 命令名自动转换

当 `shell` 为 `powershell`、`ps` 或 `pwsh`，且命令名从函数名推断时，**snake_case** 自动转换为 PowerShell 风格的 **Verb-Noun** 格式：

| 函数名 (snake_case) | 转换为 (Verb-Noun) |
|---------------------|---------------------|
| `get_child_item` | `Get-ChildItem` |
| `get_process` | `Get-Process` |
| `write_output` | `Write-Output` |
| `new_item` | `New-Item` |
| `invoke_expression` | `Invoke-Expression` |

转换规则：
- 第一个下划线前的词作为 Verb（首字母大写）
- 后面的词拼成 Noun（每个词首字母大写，连起来）
- 中间用 `-` 连接

> **注意**：显式传入命令名时不会自动转换，保持原样。

## 使用方式

```python
from vools.sys import cmd

# 函数名即命令，自动转换为 PowerShell Verb-Noun
@cmd
def get_child_item(_recurse=None):
    pass

result = get_child_item()
print(result[1])
```

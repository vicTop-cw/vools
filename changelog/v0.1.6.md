# v0.1.6

## 新增功能

### 核心模块
- 创建 `core/base.py` - 基础类定义
- 创建 `core/config.py` - 配置管理（支持 Python 3.6+）
- 创建 `core/exceptions.py` - 自定义异常类

### vic 工具类
- 创建 `vic/victools.py` - 通用工具类
- 创建 `vic/vicdate.py` - 日期处理类
- 创建 `vic/victext.py` - 文本处理类
- 创建 `vic/viclist.py` - 列表处理类

### 安全模块
- 创建 `security/safe_eval.py` - 安全表达式求值

### Box 类增强
- 支持数字索引访问（`_1`, `_2`, `_3`, ...）
- 支持切片操作（`box[0:2]`）
- 支持负数索引（`box[-1]`）

### 装饰器模块
- 添加 `shotcut.py` - 快捷装饰器（timeit, safe, throttle, debounce 等）
- 添加 `cache.py` - 缓存装饰器
- 添加 `control.py` - 控制流装饰器

### 函数式编程模块
- 添加 `iif.py` - 条件表达式
- 添加 `funcs.py` - 通用函数

# v0.1.8 (2026-06-04)

## 新增功能

- 新增 `rself` 类装饰器，实现链式调用支持
  - 限制继承方式为最多单继承或不继承
  - 方法返回 None 时返回自身实例
  - 方法返回父类实例时自动转换为子类实例
  - 支持属性、类方法、静态方法的拦截处理

## 改进

- 整合 `rself_v1.py` 和 `rself_v2.py` 的优势，创建统一的 `rself.py`
- 添加 `rself` 到 `vools.decorators` 和 `vools` 包的导出

## 测试

- 添加 `tests/test_rself.py` 测试文件，覆盖核心功能

## 删除

- 删除 `rself_v1.py` 和 `rself_v2.py`（已整合）

# v0.1.17 更新日志

> 发布日期: 2026-06-20

## 概述

大规模序列化支持：项目中所有核心类均已添加 __getstate__/__setstate__，支持 pickle 跨进程传输。

## 新功能

- 序列化支持: Result, Seq, Itor, NewOverloadManager 基础类型
- 序列化支持: X, Y, _IndexHolder 占位符类型
- 序列化支持: PipeX, PipeY 管道执行器
- 序列化支持: Selector, Overloads 选择器
- 序列化支持: _OnceWrapper (两处) 缓存执行结果
- 序列化支持: CurriedMethod 柯里化链式状态
- 序列化支持: Fusion/ClassFusion 类融合器
- 序列化支持: PipeBuilder, Observable 响应式管道
- 序列化支持: Subject, BehaviorSubject, ReplaySubject, AsyncSubject
- 序列化支持: Task, TaskQueue, TaskStorage, Worker, WorkerPool
- 序列化支持: Encryptor, Decryptor 加密器
- 序列化支持: Encoder, Decoder 编码器
- 序列化支持: Mixer_, Mixer 对象混入器
- 序列化支持: Recorder, Player 录制/回放
- 序列化支持: DateProcessor, EnhancedDateFormatter
- 序列化支持: SafeExpressionEvaluator 安全求值器
- 序列化支持: TimedCache 缓存, ConfigManager 配置
- 序列化支持: ObjectPool 对象池

## 改进

- overload 装饰器: 合并 Temp/overload.py 新模式标志系统 (Priority/AllowSyncName/Strict/Ambiguous)
- overload 装饰器: 支持非同名函数注册 + export_mode 导出模式
- iif.py: 合并 Temp/iif.py 多项改进 (双路缓存、_UNSET 哨兵值、_eval_string_condition 提取)
- 所有带 threading.Lock / threading.Event / DB 连接的类均在 __setstate__ 中重建
- 所有 __slots__ 类使用 object.__setattr__ 恢复状态
- 单例类 (X, Y) 通过 __vools_singleton__ 格式跨后端支持

## 兼容性

- overload 旧 API (is_strict/priority='first') 已删除，改用 OverloadMode 标志组合
- overloads.py 标记为 deprecated，转发到新 overload
- iif() whens 模式改用 data 参数传值而非 condition
- 序列化默认仅保证 pickle 后端完整支持；json/msgpack 对含函数引用的类型有限制

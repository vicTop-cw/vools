# v0.1.14 (2026-06-13)

## 新增功能

### 1. 响应式统计算子扩展

新增 `vools/reactive/stats_operators.py` 模块，提供 21 个统计聚合扩展算子：

**统计聚合算子**
- `median()` - 计算中位数
- `variance(ddof=0)` - 计算方差
- `std(ddof=0)` - 计算标准差
- `quantile(q)` - 计算分位数
- `arg_min()` - 返回最小值索引
- `arg_max()` - 返回最大值索引
- `n_unique()` - 计算不重复值数量

**滚动窗口算子**
- `rolling_sum(window_size)` - 滚动求和
- `rolling_min(window_size)` - 滚动最小值
- `rolling_max(window_size)` - 滚动最大值
- `rolling_mean(window_size)` - 滚动均值

**累积变换算子**
- `cum_sum()` - 累积求和
- `cum_min()` - 累积最小值
- `cum_max()` - 累积最大值
- `cum_mean()` - 累积均值
- `cum_prod()` - 累积乘积

**排序 Top-N 算子**
- `sort(key_fn=None, reverse=False)` - 排序后依次发射
- `top_k(k, key_fn=None)` - 获取最大的 k 个值
- `bottom_k(k, key_fn=None)` - 获取最小的 k 个值

**None 值处理与数学工具**
- `drop_none()` - 过滤 None 值
- `fill_none(default_value)` - 替换 None 值
- `abs()` - 绝对值
- `clamp(min_val, max_val)` - 值域限制

**嵌套流展开算子**
- `explode()` - 展开 Iterable（排除 str/bytes）
- `flatten()` - 与 explode 同语义

### 2. 编码模块

新增 `vools/encoding/` 模块，提供统一的编码/解码接口：

**核心功能**
- `Encoder` / `Decoder` 类 - 链式编码/解码
- `CodecRegistry` - 编码器注册中心
- `encodable` / `decodable` 装饰器 - 自定义编码器注册

**支持的格式**
- Base64: `b64encode`, `b64decode`
- URL: `urlencode`, `urldecode`
- JSON: `json_dumps`, `json_loads`
- Gzip: `gzip_compress`, `gzip_decompress`
- 通用接口: `serialize`, `deserialize`

### 3. 加密模块

新增 `vools/crypto/` 模块，提供统一的加密接口：

**核心功能**
- `Encryptor` 类 - 链式加密操作
- `CryptoRegistry` - 加密算法注册中心
- `encryptable` / `decryptable` 装饰器 - 自定义加密器注册

**支持的算法**
- Hash: `md5`, `sha1`, `sha256`, `sha512`
- HMAC: `hmac_md5`, `hmac_sha256`
- 密钥生成: `generate_key`, `generate_token`

### 4. Result 类型与 safe 装饰器

新增函数式错误处理支持：

**Result 类型**
- `Result.success(value)` - 创建成功结果
- `Result.failure(error)` - 创建失败结果
- `is_success` / `is_failure` - 状态检查
- `map(fn)` - 映射操作
- `unwrap()` / `unwrap_or(default)` - 获取值

**safe 装饰器**
- 将函数包装为返回 Result 类型
- 自动捕获异常并转换为 Failure

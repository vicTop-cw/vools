# CHANGELOG 0.2.4

## 修复

### Python 3.6 兼容性系统性修复

经过系统性的全量扫描（800+ 相对导入语句），发现并修复了 18 处相对导入层级错误。

**修复的文件**：

1. **vools/reactive/operators/extended_operators.py**（15 处）
   - `from .observable import Subscription` → `from ..core.observable import Subscription`
   - `from .subject import Subject` → `from ..core.subject import Subject`
   - 原因：`observable` 和 `subject` 实际位于 `reactive/core/` 子包，但被误写成本目录兄弟模块

2. **vools/reactive/operators/operators.py**（1 处）
   - `from ..data import Seq` → `from ...data import Seq`
   - 原因：在 `reactive/operators/` 下，应使用 3 个点回到 vools 根后再到 data

3. **vools/reactive/monitoring/keyboard.py**（2 处）
   - `from ...core.subject import Subject` → `from ..core.subject import Subject`
   - `from ..reactive import operators` → `from ...reactive import operators`
   - 原因：subject 在 reactive.core（深度1），用 2 个点；operators 在 reactive（深度1），用 3 个点

4. **vools/reactive/monitoring/mouse.py**（2 处）
   - 同 keyboard.py 的修复

### contextvars 兼容性问题

- **问题**：Python 3.6 不支持类型注解的泛型下标（如 `ContextVar[Optional[X]]`），运行时求值会报 `TypeError: 'type' object is not subscriptable`
- **修复**：移除 `_ctx` 变量的泛型类型注解，改为简单赋值

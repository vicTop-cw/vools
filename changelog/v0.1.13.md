# v0.1.13 更新日志

> 发布日期: 2026-06-13

## 新功能

### 1. curried 子包扩展

- 新增惰性版本操作符
  - `imap`: 惰性 map，返回 map 对象
  - `ifilter`: 惰性 filter，返回 filter 对象  
  - `iunique`: 惰性 unique，返回 generator
- 所有惰性版本支持与 toolz 兼容的接口

### 2. reactive 子包增强

- 修复 `AsyncIOScheduler` 废弃警告（Python 3.13+ 兼容性）
- 优化调度器初始化逻辑，优先使用当前运行的事件循环

### 3. iif 模块完善

- 添加 `otherwise` 方法作为 `default` 的别名
- 添加 `evaluate` 和 `evaluateEx` 方法
- 完善链式调用锁定逻辑

## 改进

### 1. curry 装饰器优化

- 优化参数绑定逻辑，减少重复计算
- 改进柯里化函数的错误提示信息

### 2. 测试覆盖率提升

- curried 模块测试覆盖率达到 100%
- 添加线程安全测试用例
- 完善边界条件测试

### 3. 性能优化

- map/filter/unique 添加惰性选项，支持按需求值
- 优化柯里化函数的调用路径

## 修复

### 1. 已修复问题

- **P001**: `ConditionBuilder` 缺少 `otherwise` 方法 ✅
- **P003**: `asyncio.get_event_loop()` 废弃警告 ✅

### 2. 其他修复

- reduce 函数空迭代器处理修复
- groupby 测试用例预期结果修正
- nth 函数负索引支持修复

## 兼容性

- 支持 Python 3.6+
- 与 toolz.curried 模块 API 兼容
- 与 RxPy 4.0 操作符命名兼容

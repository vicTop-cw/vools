# CHANGELOG 0.4.9

## 主要更新

### Itor 可控迭代器性能优化

#### Nim 版本重构
- **性能提升 18-22 倍**：基础迭代从 158ms 降至 8ms（100000 数据）
- **移除 pickle 序列化**：数据完全在 Python 端处理，避免跨语言数据传递开销
- **Nim 仅负责线程同步**：Lock/Cond 控制，不处理具体数据
- **Python 端使用 deque**：迭代直接从源迭代器取值，无需 ctypes 调用

#### 无限迭代器支持
- 新增对生成器和无限流的完整支持
- 懒加载模式，按需取值，内存占用恒定
- 修复之前无法处理无限迭代器的问题

#### 架构改进
- 采用"Python 处理数据 + Nim 处理同步"的混合架构
- 每次 `next()` 不再调用 ctypes，仅控制操作（pause/resume/stop/restart）调用 Nim
- 保持原有 API 完全兼容

### 测试增强

- 新增性能对比测试 `tests/data/test_itor_performance.py`
- 覆盖基础迭代、带插队、重启、初始化开销、无限迭代器等场景
- 支持正确计算性能提升倍数

## 兼容性

- Python 3.6+
- 已验证版本：3.13.x
- 破坏性 API 变更：无，完全向后兼容 0.4.8

## 使用方式

```python
from vools.data.itor import Itor
from vools.data.itor_nim import Itor as ItorNim

# Python 版本（功能完整）
itor = Itor(range(100000))
for item in itor:
    pass

# Nim 版本（高性能）
itor_nim = ItorNim(range(100000))
for item in itor_nim:
    pass

# 支持无限迭代器
def infinite():
    i = 0
    while True:
        yield i
        i += 1

itor = Itor(infinite())
for _ in range(100):
    next(itor)  # 正常工作，不会预取全部数据
```

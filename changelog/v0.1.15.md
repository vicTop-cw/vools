# v0.1.15 (2026-06-15)

## 新增功能

### 1. 响应式键鼠监控模块

新增 `vools/reactive/keyboard_mouse.py`，提供完整的键盘和鼠标事件监控与模拟：

**数据类型**
- `KeyEventType(IntEnum)` - 键盘事件类型：KEY_DOWN, KEY_UP, KEY_HOLD
- `MouseEventType(IntEnum)` - 鼠标事件类型：MOVE, LEFT_DOWN, LEFT_UP, RIGHT_DOWN, RIGHT_UP, MIDDLE_DOWN, MIDDLE_UP, SCROLL, DRAG
- `KeyModifier(IntFlag)` - 修饰键标志：SHIFT, CTRL, ALT, WIN, CAPSLOCK（可组合）
- `KeyData` - 结构化键盘事件数据（支持 JSON/Pickle 序列化）
- `MouseData` - 结构化鼠标事件数据（支持 JSON/Pickle 序列化）

**监控后端**
- Windows: 低级钩子（SetWindowsHookExW WH_KEYBOARD_LL / WH_MOUSE_LL）
- 非 Windows: 轮询后端（GetAsyncKeyState / GetCursorPos）

**核心组件**
- `KeyboardDispatcher` / `MouseDispatcher` - 事件分发器
- `KeySubject` / `MouseSubject` - 带监控能力的 Subject（继承 Subject）
- `KeyObserver` / `MouseObserver` - 按事件类型路由的观察者

**模拟 I/O**
- `write_to_keyboard()` - 模拟键盘输入（SendInput）
- `write_to_mouse()` - 模拟鼠标操作（移动、点击、滚轮）

**自我过滤机制**
- 通过签名登记机制过滤自身模拟产生的事件，避免循环触发

**工厂函数**
- `from_keyboard()` - 创建键盘监控 Observable
- `from_mouse()` - 创建鼠标监控 Observable

### 2. 响应式剪贴板监控模块

新增 `vools/reactive/clipboard.py`，提供剪贴板内容监控与写入：

**数据类型**
- `ClipChangeType(IntEnum)` - 剪贴板内容类型：TEXT, FILES, IMAGE, HTML, RTF, CLEAR, OTHER
- `ClipData` - 结构化剪贴板数据（支持 JSON/Pickle 序列化）

**监控后端**
- Windows: AddClipboardFormatListener + 隐藏窗口消息循环（纯 ctypes）
- 非 Windows: tkinter / threading.Event 轮询

**核心组件**
- `ClipboardDispatcher` - 剪贴板监控与分发器
- `ClipboardSubject` - 带监控能力的 Subject
- `ClipboardObserver` - 按内容类型路由的观察者

**自我过滤机制**
- 下游写回剪贴板时登记内容签名，避免重复触发

**工厂函数**
- `from_clipboard()` - 创建剪贴板监控 Observable
- `write_to_clipboard()` - 响应式操作符写入剪贴板

### 3. 响应式文件系统监控模块

新增 `vools/reactive/file_watcher.py`，提供文件变更监控：

**数据类型**
- `FileClipChangeType(IntEnum)` - 文件变更类型：CREATED, MODIFIED, DELETED, RENAMED, MOVED_IN, MOVED_OUT, ACCESS, ATTRIB
- `FileData` - 结构化文件事件数据（支持 JSON/Pickle 序列化）

**监控后端**
- Windows: ReadDirectoryChangesW + OVERLAPPED I/O + 隐藏窗口消息循环
- macOS: FSEvents API
- Linux: inotify_init / inotify_add_watch + epoll
- 其他平台: polling 保底路径

**核心组件**
- `FileDispatcher` - 文件系统监控与分发器
- `FileSubject` - 带监控能力的 Subject
- `FileObserver` - 按变更类型路由的观察者

**工厂函数**
- `from_filesystem()` - 创建文件监控 Observable
- `write_to_filesystem()` - 响应式操作符写入文件

### 4. 响应式文件夹监控模块

新增 `vools/reactive/folder_watcher.py`，提供目录级变更监控：

**数据类型**
- `FolderClipChangeType(IntEnum)` - 目录变更类型：FOLDER_CREATED, FOLDER_DELETED, FOLDER_RENAMED, FOLDER_MOVED_IN, FOLDER_MOVED_OUT, FOLDER_ATTRIB, FOLDER_CONTENT
- `FolderData` - 结构化目录事件数据（支持 JSON/Pickle 序列化）

**监控后端**
- Windows: ReadDirectoryChangesW + 线程池（过滤目录事件）
- macOS: FSEvents API
- Linux: inotify + epoll（过滤 IN_ISDIR 标志）
- 其他平台: polling 保底路径

**核心组件**
- `FolderDispatcher` - 目录监控与分发器
- `FolderSubject` - 带监控能力的 Subject
- `FolderObserver` - 按变更类型路由的观察者

**工厂函数**
- `from_foldersystem()` - 创建目录监控 Observable
- `write_to_foldersystem()` - 响应式操作符创建目录

### 5. 函数签名缓存模块

新增 `vools/sig_cache/` 模块，为大量使用 `inspect.signature()` 的场景提供高性能缓存：

**核心功能**
- `get_signature()` - 带 LRU 缓存的签名获取
- `add_custom_sig()` - 手动注册自定义签名
- `cached_getsignature()` - 装饰器：为函数附加 `__cached_sig__` 属性

**缓存管理**
- 自动 LRU 淘汰（上限 4096 条目）
- `remove_signature()` - 从缓存删除指定函数签名
- `clear_cache()` - 清空全局缓存
- `cache_info()` - 返回缓存统计信息

**预加载**
- 自动预加载常见内置函数签名（print, len, range, map, filter 等）
- 避免首次调用 inspect.signature 的开销

**性能提升**
- 重复调用场景下加速比可达 100×~2000×
- 线程安全（CPython GIL 保护 dict 读写）

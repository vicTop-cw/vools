# CHANGELOG 0.2.3

## 主要更新

### 导入规范统一：全面改为相对导入

- **子包间全部使用相对导入**：vools 包内所有子模块间的导入由绝对导入（`from vools.xxx import ...`）统一改为相对导入（`from ..xxx import ...`），提升包内聚性，支持解压式安装场景下的正确导入
- **涉及模块**：bridge、reactive、serialize、task、functional、decorators、oop、sql、api、sys、curried 等所有子包
- **验证结果**：所有核心测试通过，导入链路完整

### autopypi 发布流程优化

- **新增前置检查**：发布前自动检查 PyPI 最新版本号和对应 changelog 文件，不符合条件则不发布
- **移除自动修改**：不再自动创建 changelog 空文件、不再自动修改源文件版本号，改为纯检查模式
- **发布流程更可控**：版本号和 changelog 由人工维护，autopypi 只负责验证和执行发布

## 修复

- **bridge/_base.py 相对导入层级错误**：修正为 `from ..core` 而非 `from ...core`
- **bridge/manager.py 相对导入层级错误**：修正为 `from ..core` 而非 `from ...core`

## 统计数据

- **相对导入改造文件**: 54 个
- **autopypi 新增强制检查**: 2 项（PyPI 版本号 < 当前版本、changelog 文件存在）

## 安装使用

```bash
pip install vools==0.2.3
```

或从源码安装：

```bash
git clone https://github.com/vicTop-cw/vools.git
cd vools
git checkout main
pip install -e .
```

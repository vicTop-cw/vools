# CHANGELOG 0.2.0

## 主要更新

### Bridge 子包重大升级

- **新增 17 种语言支持**: C, C++, C#, Dart, FreeBASIC, Go, Java, Julia, Kotlin, Lua, Mojo, MoonBit, Nim, PHP, R, Ruby, Rust, Scala, Swift, TypeScript, VB.NET, VBScript, Zig, Cangjie, Perl, PowerShell, Shell 等 27 种语言桥接支持
- **统一装饰器接口**: 所有语言模块装饰器统一为基类 `LangBridge.decorator()` 接口，参数命名一致，功能统一
- **Mode 参数支持**: 新增 `mode` 参数，支持 NORMAL/DEBUG/FORCE/ONLY_RUN/ONLY_CODE 五种运行模式
- **签名缓存机制**: 为 bridge 子包实现独立的签名缓存（BridgeSigCache），每种语言一个缓存实例，LRU 淘汰策略
- **WSL 环境适配**: Kotlin、Swift、Dart、MoonBit 等语言支持通过 WSL 编译运行，Windows 环境无缝使用 Linux 编译器

### Python 3.6 兼容性

- **全面降级到 3.6+**: 所有源代码确保在 Python 3.6+ 环境下可运行
- **dataclass 兼容版**: `vools.core.dataclass_compat` 提供兼容版 dataclass，替代直接导入 dataclasses 模块
- **subprocess 兼容**: `capture_output` 参数全部替换为 `stdout=PIPE, stderr=PIPE`，兼容 3.6
- **类型注解兼容**: `list[int]`/`dict[str, int]` 等内置泛型全部替换为 `typing.List`/`typing.Dict`
- **移除 3.7+ 语法**: 全面清理 f-string = 调试语法、match/case、| 联合类型等 3.7+ 特性

### 新增模块

- **vools.bridge**: 多语言桥接子包，27 种编程语言支持
  - `vools.bridge.core`: 核心模块（类型定义、签名缓存、装饰器、加载器、序列化）
  - 27 个语言子模块
  - `LangBridge` 基类提供统一接口
- **vools.api**: CLI 命令行接口子包
- **vools.sql**: SQL 相关子包
- **vools.sys**: 系统工具子包

### 文档完善

- **子包 README 全覆盖**: 所有子包、孙包均有完整 README.md，包含模块简介、主要功能、使用示例
- **新增 8 个 README**: reactive/core、reactive/monitoring、reactive/operators、serialize/backends、serialize/callable、task/core、task/decorators、bridge/python
- **README 内容标准化**: 统一包含模块名、简介、功能列表、代码示例

## 修复

- **Box 类装饰器问题**: 修复 `Box` 类方法误用 `@box` 装饰器导致的 self 包装异常
- **Box 类型转换**: 新增 `__int__`、`__float__`、`__complex__`、`__index__` 类型转换方法
- **循环导入问题**: 修复多处潜在的循环导入
- **相对导入**: 所有 sys.insert 控制导入方式改为相对导入

```bash

```

```bash
git clone https://github.com/vicTop-cw/vools.git
cd vools
git checkout main
pip install -e .
```

# vools.reactive.operators — 操作符集合

响应式操作符，包括标准操作符和扩展操作符。

## 标准操作符

`map`, `filter`, `take`, `skip`, `debounce`, `throttle`, `merge`, `concat`, `zip`, `combine_latest`

## 扩展操作符

`from_range`, `from_callable`, `window`, `switch`, `cache`, `parallel`, `retry_with_backoff`, `circuit_breaker`

## 统计操作符

`median`, `variance`, `std`, `rolling_sum`, `rolling_mean`, `cum_sum`, `top_k`, `bottom_k`

## 监控操作符

连接 `vools.reactive.monitoring` 的桥接操作符。

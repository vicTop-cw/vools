# vools 包

Python 函数式编程工具集根包。

## 子包一览

| 子包 | 说明 |
|------|------|
| `cache` | 缓存（memorize, once, persist, sigcache） |
| `core` | 核心（基础类、异常、配置、dataclass 兼容层） |
| `crypto` | 加密 |
| `curried` | 柯里化函数（已弃用） |
| `data` | 数据结构（Seq, VList, VText） |
| `datetime` | 日期时间工具 |
| `decorators` | 装饰器（curry, overload, retry, trd） |
| `encoding` | 编码工具 |
| `functional` | 函数式编程（Result, Pipe, Box） |
| `oop` | OOP 扩展 |
| `reactive` | 响应式编程 |
| `recorder` | 操作录制 |
| `security` | 安全求值 |
| `serialize` | 序列化 |
| `task` | 任务队列 + DAG + 规则引擎 |
| `utils` | 通用工具 |

各子包详细文档见对应 `README.md`。

# vools.bridge.php - PHP 语言桥接模块

PHP 动态执行装饰器，通过 subprocess 调用 php 解释器执行 PHP 代码。

---

## 1. 语言简介

PHP（PHP: Hypertext Preprocessor）是一种广泛使用的开源通用脚本语言，特别适用于 Web 开发。PHP 是一种解释型语言，无需编译即可由 PHP 解释器执行。

本模块将 Python 函数转换为 PHP 代码，通过 `php` 命令行解释器执行，实现跨语言桥接。

**设计特点：**
- 解释型语言桥接（直接执行 .php 文件）
- 基于 JSON 的进程间数据交换
- 装饰器模式：`@php` 装饰器，函数体返回 PHP 代码字符串
- 支持异步执行和回退机制

## 2. Bridge 类名

```python
PHPBridge
```

**继承关系：**
```
LangBridge (ABC)
    └── PHPBridge
```

**类属性：**
| 属性 | 值 | 说明 |

## 3. 支持的功能

### 3.1 单函数装饰器模式

使用 `@php` 装饰器，将 Python 函数转换为 PHP 代码，首次调用时自动编译（写入 .php 文件）并执行。

### 3.2 仅代码模式（only_code）

使用 `mode='ONLY_CODE'`，只生成 PHP 代码不执行，支持将代码写入指定文件。

### 3.3 项目模式（project）

使用 `project_dir` 参数，编译整个 PHP 项目目录，支持入口函数调用。

### 3.4 异步模式

使用 `async_mode=True`，返回 asyncio Future，支持异步调用。

### 3.5 回退机制

使用 `fallback` 参数，当 PHP 环境不可用或执行失败时，自动调用 Python 回退函数。

### 3.6 依赖管理

支持 `deps` 参数声明依赖函数，自动在目标函数之前生成依赖代码。

## 4. 运行环境要求

### 4.1 PHP 解释器

**Windows：**
- 安装 PHP（如通过 XAMPP、WampServer 或独立安装）
- 确保 `php.exe` 在系统 PATH 中，或位于以下常见路径：
  - `C:\php`
  - `C:\xampp\php`
  - `C:\wamp64\bin\php`

**Linux：**
- 通过包管理器安装：`sudo apt install php-cli` 或 `sudo yum install php`
- 确保 `php` 命令可用

**macOS：**
- 通过 Homebrew 安装：`brew install php`
- 或使用 MAMP/XAMPP

### 4.2 版本要求

- PHP 5.6 或更高版本（推荐 PHP 7.x/8.x）
- 需要支持 `json_encode()` 和 `json_decode()` 函数

### 4.3 验证安装

```python
from vools.bridge.php import php_compiler_available, get_php_version

if php_compiler_available():
    print(f"PHP 可用: {get_php_version()}")
else:
    print("PHP 不可用，请安装 PHP")
```

## 5. 类型映射

### 5.1 Python → PHP 类型映射

| Python 类型 | PHP 类型 | 说明 |
|-------------|----------|------|
| `int` | `int` | 整数 |
| `float` | `float` | 浮点数 |
| `str` | `string` | 字符串 |
| `bool` | `bool` | 布尔值 |
| `list` | `array` | 数组 |
| `dict` | `array` | 关联数组 |
| `type(None)` | `NULL` | 空值 |

### 5.2 PHP → ctypes 类型映射

| PHP 类型 | ctypes 类型 | 说明 |
|----------|-------------|------|
| `int` / `integer` | `c_int` | 整数 |
| `float` / `double` | `c_double` | 浮点数 |
| `string` | `c_char_p` | 字符串指针 |
| `bool` / `boolean` | `c_bool` | 布尔值 |
| `array` | `c_void_p` | 数组指针 |
| `NULL` / `void` | `None` | 无返回值 |

### 5.3 函数签名类型推断

当 `auto_signature=True` 时，装饰器自动从 Python 类型注解推断 PHP 类型：

```python
@php
def add(x: int, y: int) -> int:
    return "return $x + $y;"
# 推断为: function add(int $x, int $y): int
```

## 6. 快速使用示例

### 6.1 基础用法

```python
from vools.bridge.php import php

@php
def fib(n: int) -> int:
    return """
    if ($n <= 1) {
        return 1;
    } else {
        return fib($n - 1) + fib($n - 2);
    }
    """

result = fib(10)
print(result)  # 89
```

### 6.2 带类型注解的函数

```python
@php
def add(x: int, y: int) -> int:
    return "return $x + $y;"

print(add(1, 2))  # 3
```

### 6.3 字符串处理

```python
@php
def greet(name: str) -> str:
    return '"Hello, " . $name . "!"'

print(greet("World"))  # Hello, World!
```

### 6.4 数组操作

```python
@php
def sum_array(arr: list) -> int:
    return """
    $sum = 0;
    foreach ($arr as $item) {
        $sum += $item;
    }
    return $sum;
    """

print(sum_array([1, 2, 3, 4, 5]))  # 15
```

### 6.5 异步模式

```python
@php(async_mode=True)
def compute(x: int) -> int:
    return "return $x * $x;"

result = await compute(10)
print(result)  # 100
```

### 6.6 带回退函数

```python
@php(fallback=lambda x: x * 2)
def maybe_unavailable(x: int) -> int:
    return "return $x * 3;"

# 如果 PHP 不可用，使用 lambda 回退
print(maybe_unavailable(5))  # 10
```

## 7. only_code 模式示例

`only_code` 模式只生成 PHP 代码，不执行，适用于代码生成和检查。

### 7.1 获取生成的代码

```python
@php(mode='ONLY_CODE')
def my_func(x: int) -> int:
    return "return $x * 2;"

code = my_func(10)
print(code)
```

**输出：**
```php
<?php
// Auto-generated by vools.bridge.php

// 解析参数
$args_json = '[10]';
$args = json_decode($args_json, true);

function my_func(int $x): int {
return $x * 2;
}

// 调用函数并输出结果
$result = my_func(...$args);

echo json_encode($result, JSON_UNESCAPED_UNICODE);
```

### 7.2 写入文件

```python
@php(mode='ONLY_CODE', output_file='output/my_func.php')
def my_func(x: int) -> int:
    return "return $x * 2;"

my_func(10)  # 代码会写入 output/my_func.php
```

### 7.3 追加到文件

```python
@php(mode='ONLY_CODE', output_file='output/shared.php', write_mode='append')
def helper1() -> int:
    return "return 1;"

@php(mode='ONLY_CODE', output_file='output/shared.php', write_mode='append')
def helper2() -> int:
    return "return 2;"
```

### 7.4 FORCE 模式

`FORCE` 模式强制重新生成脚本并保存，返回脚本路径但不执行：

```python
@php(mode='FORCE')
def my_script(x: int) -> int:
    return "return $x;"

script_path = my_script(10)
print(f"脚本已保存到: {script_path}")
```

## 8. project 模式示例

`project_dir` 参数用于处理整个 PHP 项目目录。

### 8.1 项目目录结构

假设有如下项目结构：

```
my_php_project/
├── main.php
├── utils.php
└── math/
    ├── operations.php
    └── helpers.php
```

### 8.2 项目模式装饰器

```python
@php(project_dir='./my_php_project', entry='main')
def run_project():
    pass

result = run_project()
```

### 8.3 执行特定入口函数

```python
# 执行 calc 函数（不是 main）
@php(project_dir='./my_php_project', entry='calc')
def run_calc():
    pass

result = run_calc(10, 20)
```

### 8.4 调用项目中的函数

```python
from vools.bridge.php import _php_bridge

# 编译项目
artifact_path = _php_bridge.compile_project(
    './my_php_project',
    entry='process_data',
    output_dir='./output'
)

# 调用项目中的函数
result = _php_bridge.call_func(
    artifact_path,
    'process_data',
    args=(1, 2, 3),
    ret_type=int
)
```

### 8.5 直接运行项目

```python
from vools.bridge.php import _php_bridge

# 返回 (returncode, stdout, stderr)
returncode, stdout, stderr = _php_bridge.run_project(
    './my_php_project',
    entry='main',
    args=('arg1', 'arg2')
)

print(stdout)
```

## 9. 注意事项

### 9.1 PHP 版本兼容性

- 装饰器生成的代码使用 PHP 7+ 语法（类型声明、箭头函数等）
- 如果需要 PHP 5.6 兼容，请设置 `auto_signature=False` 并手动编写代码

### 9.2 安全性

- 生成的 PHP 代码通过 `json_decode()` 解析参数，避免 `eval()` 安全风险
- 不要在函数体中直接执行不可信的用户输入

### 9.3 性能考虑

- PHP 是解释型语言，每次调用都会执行 `php` 子进程
- 对于高频调用场景，建议使用编译型语言桥接（如 C、Rust、Nim 等）
- 缓存机制可以减少重复编译开销

### 9.4 Windows 路径问题

- 在 Windows 上使用 WSL 可以提高执行效率
- 确保 PHP 路径不包含空格或特殊字符

### 9.5 错误处理

- PHP 执行失败时，会抛出 `RuntimeError`，包含 stderr 和 stdout 信息
- 使用 `fallback` 参数可以在 PHP 不可用时优雅降级

### 9.6 数组/列表参数

PHP 的数组是弱类型，Python 的 `list` 和 `dict` 都映射为 PHP 的 `array`：

```python
@php
def process_data(data: list) -> list:
    return """
    return array_map(function($item) {
        return $item * 2;
    }, $data);
    """

print(process_data([1, 2, 3]))  # [2, 4, 6]
```

### 9.7 JSON 序列化

- 参数和返回值通过 JSON 格式传递
- 确保 PHP 的 `json_encode()` 和 `json_decode()` 可用
- 返回值自动从 JSON 反序列化为 Python 对象

## API 参考

### 核心函数

| 函数 | 说明 |
|------|------|
| `php(func=None, ...)` | PHP 装饰器 |
| `phpe` | `php` 的别名 |
| `php_compiler_available()` | 检查 PHP 是否可用 |
| `compile_and_run(php_code, ...)` | 直接编译运行 PHP 代码 |
| `compile_and_run_async(...)` | 异步编译运行 |
| `_php_bridge` | PHPBridge 实例 |

### PHPFuture

异步调用返回 `PHPFuture` 对象，支持：
- `result(timeout=None)` - 获取结果
- `__await__()` - 用于 asyncio

### LangBridge 方法

| 方法 | 说明 |
|------|------|
| `compiler_available()` | 检查编译器是否可用 |
| `generate_code(spec)` | 生成 PHP 代码 |
| `compile_code(code, func_name, cache_dir)` | 编译代码（写入文件） |
| `compile_project(project_dir, entry, output_dir)` | 编译项目 |
| `call_func(lib_path, func_name, args, ret_type)` | 调用函数 |
| `run_project(project_dir, entry, args, cache_dir)` | 运行项目 |

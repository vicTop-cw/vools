vools-rhop 配置生成器

静态页面：不联网、不起服务，填完直接生成 config.json。敏感信息支持明文 / 密文双区， 点「生成密文」会直接在浏览器内用 rhop 的 Fernet 方案加密（与 Python 侧互通），并清空明文区。

1. 方向与命名

没有 P0/P1/P2/P3 跳板角色：只有 A（发）/ B（收）/ C（中转到不了时用）。

2. 密钥（加解密其他密文的钥匙）

3. 共享介质（shared path）

双方共同可达的介质；写读两端可以形态不同（本地目录 / UNC / file:// / http://）。 数据库与心跳文件都落在这里。

4. 队列存储与心跳

B 每 5 秒把 UTC 时间戳写进该文件；一直不动 = 服务挂了； 往里写 closed = 让 B 优雅停机。存储后端可在配置里切换， 接 PostgreSQL 等只需在代码里 register_store(kind, factory)。

5. 执行白名单（B 端安全边界）

默认只放行代码内注册的动作与处理器；要跑命令行请加 cli:python、 cli:bash 这类条目（shell=true 需另加 cli:shell）。

6. 在线通道 / 中转（可选）

在线通道按优先级使用；都没有时回退 shared path。中转 C 仅在 A/B 不可直连时用。

7. 加密工具（用于所有密文区）

页内用 PBKDF2-HMAC-SHA256(100000) + AES-128-CBC + HMAC-SHA256（即 Fernet）加密， 与 python -m vools.rhop.secret enc "<明文>" 完全互通。密钥文本只用于本地计算，不上传、不落盘。

生成的配置

点「生成配置」↖ 或直接点「载入示例」。

部署三步

1. 生成两份额配置：A 端 role=A、B 端 role=B，共享同一介质。
2. B 端常驻：python -m vools.rhop.task --config rhop-B.json serve
3. A 端提交：python -m vools.rhop.task --config rhop-A.json submit --file tasks.json
